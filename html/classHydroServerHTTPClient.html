Detailed Description

Posts observations straight to a HydroServer instance.

Each call to publishObservation() sends one POST to /api/sensorthings/v1.1/Observations, with your API key in the X-Api-Key header. The connection is kept open between requests, so posting several readings in a row doesn't reconnect each time.

WiFiSSLClient sslClient;
HydroServerHTTPClient hsClient(sslClient, "playground.hydroserver.org", 443,
API_KEY);
if (!hsClient.publishObservation(temperature, "2026-09-23T18:30:00Z")) {
Serial.println(hsClient.getLastResponseBody());
}

Posts several observations with the same timestamp.

Sends one request per observation. A failed post doesn't stop the rest, but this doesn't tell you which ones failed. If you need to know, call publishObservation() in a loop instead.
