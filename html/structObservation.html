Detailed Description

One sensor reading, ready to send.

The struct keeps pointers to the strings you give it, not copies, so use string literals or strings that last for the whole program (globals or static).

Observation temperature("temperature", "<datastream-uuid>", "temp-sensor-1");
temperature.value = 21.7;
