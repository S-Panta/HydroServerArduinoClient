Detailed Description

Helper class for Espressif ESP32 Wi-Fi Bee on the Mayfly.

Handles both plain TCP and TLS, so it works for MQTT, HTTP and HTTPS. The ESP32 needs one extra step after joining Wi-Fi: call extraSetupForMQTT() before MQTT, or extraSetupForHTTPS() before HTTPS.

ESP32Bee modem(Serial1, 18);
HydroServerMQTTClient mqttClient(*modem.createClient(), "broker.local");
void setup() {
Serial1.begin(57600);
modem.connectToInternet(WIFI_SSID, WIFI_PASS);
modem.extraSetupForMQTT();
// ...then set up and connect mqttClient
}

Finds the baud rate the Bee is set to.

Most ESP32 Bees run at 115200 or 57600, but not all of them. This tries the common rates from 9600 up to 115200 and can take a while, so use it when setting up a new Bee, not in a deployed sketch.

Parameters
serialSerial port the Bee is on.
Returns

◆ extraSetupForHTTPS()

void ESP32Bee::extraSetupForHTTPS ( const char *  host,
const int  port 
)

Prepares the ESP32 for HTTPS to one host.

Some servers, the HydroServer playground among them, host several sites on one IP address. They need the host name during the TLS handshake (SNI) to pick the right certificate, and the ESP32 doesn't send it unless told to. This sets the host name and opens the TLS connection.

It also does what extraSetupForMQTT() does, so you don't need both. Call it after connectToInternet().

Parameters
hostServer host name, such as playground.hydroserver.org.
portServer port, usually 443.

◆ getNISTTime()

uint32_t ESP32Bee::getNISTTime ( )
overridevirtual

Gets the current UTC time from a network time server.

The time is counted in seconds since 1 January 2000, which is what the Mayfly's DS3231 clock uses, so you can pass it straight to rtc.setDateTime(). Add 946684800 to get Unix time.

Check the result before setting the clock: a failed lookup can return 0. See each modem for details.

Returns
Seconds since 2000-01-01 00:00:00 UTC.

On the ESP32 this syncs with pool.ntp.org and waits up to 30 seconds for an answer.
