Turns an observation into SensorThings JSON.

The result looks like this:

{
"Datastream": { "@iot.id": "<datastreamId>" },
"result": 21.7,
"phenomenonTime": "2026-09-23T18:30:00Z"
}

You don't normally need to call this yourself. Both clients call it when publishing.

Parameters
observationThe reading to serialize.
phenomenonTimeWhen the reading was taken, as an ISO 8601 UTC string.
Returns
The JSON payload.
