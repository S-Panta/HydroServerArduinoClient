28// NOTE: You have to preconfig the sensor before you run this code. This code
29// use "aM8!" as measurement command. This means, you have to preset how many
30// average of the measurement you want to take. To setup, run
31// "SDI12_command_test.ino" file and run `aXCONFIG1=0,4,100,0!`. Temperature
32// will be in celcius, Water depth in meter and the multiplier 100 will change
33// to centimeter Also do "aXCONFIG2 = 20!" to set instrument to make 20
34// measurements. CS451_MEASUREMENT_TIME_MS will be dependent on how many average
35// you want to take.
