Detailed Description

Publishes observations to an MQTT broker.

Observations are published to siteCode/clientId/sensorId/observedProperty, so call setSiteCode() and setClientID() before connecting. The payload is the same SensorThings JSON that HydroServerHTTPClient sends.

The broker only relays messages. To get them into HydroServer you need a separate service that subscribes to the broker and writes the observations to HydroServer.

WiFiClient wifiClient;
HydroServerMQTTClient mqttClient(wifiClient, "test.mosquitto.org");
void setup() {
// ...join Wi-Fi and set the clock first
mqttClient.setSiteCode("mysite");
mqttClient.setClientID("logger01");
mqttClient.setLastWill("offline");
mqttClient.connectToBroker();
}
void loop() {
mqttClient.poll();
// ...when it's time for a reading:
mqttClient.publishObservation(temperature, getISO8601Time());
}

◆ getConnectionError()

int HydroServerMQTTClient::getConnectionError ( )

Returns the error code from the last failed connection attempt.

The codes come from ArduinoMqttClient. Negative numbers are network problems: -2 usually means the broker host or port can't be reached. Positive numbers mean the broker refused the connection, for example because of a wrong user name or password.

◆ poll()

void HydroServerMQTTClient::poll ( )

Keeps the connection alive and delivers incoming messages.

Call this on every pass through loop(). It sends the keep-alive pings and runs your onMessage() handler when a message arrives. If it isn't called often enough, the broker decides the logger is gone and drops the connection. See setKeepAliveInterval().

◆ setCleanSession()

void HydroServerMQTTClient::setCleanSession ( bool  cleanSession)

Chooses whether the broker forgets this client between connections.

With true, the broker drops this client's subscriptions and queued messages every time it reconnects. With false (the default) it keeps them, which only works if the client ID stays the same. For QoS 0 messages it makes no difference.

Parameters
cleanSessiontrue to start fresh on every connection.

◆ setKeepAliveInterval()

void HydroServerMQTTClient::setKeepAliveInterval ( unsigned long  seconds)

Sets how often, in seconds, the client pings the broker.

The broker drops a client it hasn't heard from in about 1.5 times this interval. The default is 60 seconds. If your logger sleeps between readings, either make this longer than the sleep or reconnect after waking. Call it before connecting.

Parameters
secondsKeep-alive interval in seconds.

Sets the message the broker sends out if this logger drops off without disconnecting cleanly.

The message goes to siteCode/clientId/lwt, so call setSiteCode() and setClientID() first, and call this before connecting. QoS 1 or higher is recommended so the broker doesn't lose the message.

Parameters

Returns
