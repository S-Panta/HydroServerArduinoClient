Detailed Description

Publishes observations to an MQTT broker.

Observations are published to siteCode/clientId/sensorId/observedProperty, so call setSiteCode() and setClientID() before connecting. The payload is the same SensorThings JSON that HydroServerHTTPClient sends.

The broker only relays messages. To get them into HydroServer you need a separate service that subscribes to the broker and writes the observations to HydroServer.

WiFiClient wifiClient;
HydroServerMQTTClient mqttClient(wifiClient, "test.mosquitto.org");
void setup() {
// ...join Wi-Fi and set the clock first
mqttClient.setSiteCode("mysite");
mqttClient.setClientID("logger01");
mqttClient.setLastWill("offline");
mqttClient.connectToBroker();
}
void loop() {
mqttClient.poll();
// ...when it's time for a reading:
mqttClient.publishObservation(temperature, getISO8601Time());
}

◆ setCleanSession()

void HydroServerMQTTClient::setCleanSession ( bool  cleanSession)

Sets whether the MQTT client starts a clean session.

When set to true, the broker starts a clean session by discarding any existing session state associated with this client ID. The broker does not retain the client's subscriptions or queued messages after the client disconnects.

When set to false, the broker creates or resumes a persistent session. The broker retains the client's subscriptions and queues eligible QoS 1 and QoS 2 messages while the client is disconnected. The client must reconnect using the same client ID to resume the session.

For QoS 0 messages, the broker does not guarantee message delivery while the client is disconnected.

Parameters
cleanSessiontrue to start a clean session; false to resume or create a persistent session.

void HydroServerMQTTClient::setKeepAliveInterval ( unsigned long  seconds)

Sets the MQTT keep-alive interval in seconds.

The client must send a control packet within this interval. If the broker receives no packet within 1.5 times this interval, it may disconnect the client. If your logger sleeps between readings, increase the interval or reconnect after waking.

Parameters
secondsKeep-alive interval in seconds (default: 60 seconds).
